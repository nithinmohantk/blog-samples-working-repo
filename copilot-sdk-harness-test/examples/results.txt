Other observations
- send_and_wait(timeout=60) stops waiting, not the session: the loop continued until session.abort().
- execution.limits.max_ai_credits: minimum 30; with a BYOK model it did not stop 613 model calls in 20 s.
- No permission handler: every tool call, reads included, was denied ("user not available").
- mode="empty" requires per-tenant storage (base_directory or session_fs) and an explicit available_tools list.
- A low-level Tool handler must return ToolResult; returning a plain string failed the call.
- On resume after a crash, the runtime told the model: "Tool execution was interrupted before a result was
  recorded. Its effects may be absent, partial, or already complete" and did not re-run the tool itself.
- Sandbox default policy without credential masking still exposed the secret on the VM.
